# apps/admin

Yönetim paneli — **Next.js**. Faz 2'de oluşturulacak. MVP'de bu işler korumalı bir yönetici CLI'ı ile yapılır.

Kurallar:
- Ayrı bir alt alan adında yayınlanır; oturum çerezi yalnızca o alt alan adına yazılır (SES-01).
- Girişte MFA zorunludur (AUT-01).
- Mümkünse yalnızca belirli IP'lerden veya VPN üzerinden erişilir.
